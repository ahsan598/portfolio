Project Overview

This project is a scalable and secure multi-tier web application on AWS using Terraform for automated infrastructure provisioning. Designed a custom VPC with isolated public and private subnets, multiple application servers for load balancing, and a managed database layer for high availability and scalability.

Implemented robust security using AWS Security Groups and IAM roles to enforce least-privilege access. Terraform ensures repeatable and auditable deployments, enabling consistent infrastructure management across environments. This project demonstrates expertise in cloud architecture, secure networking, infrastructure as code (IaC), and scalable web application deployment.
